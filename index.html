1. Workflow & Interface

Step 1
Input / Output Pick audio files, set an output folder, and choose WAV for DAW use.
Step 2
Method & Model Select an engine in the left column, then pick your model and target stems.
Step 3
Sample Mode Enable Sample Mode (5–15s clip) to audition models before running a full track.
Step 4
Start Processing Verify GPU/CPU setting, click Start Processing, and monitor the bottom log.
Top Bar: Select Input (batch supported) · Select Output · Format (WAV / FLAC / MP3)

Left: Process Method

  • MDX-Net (2-stem vocals/inst)
  • Demucs (4 or 6 stems)
  • VR Architecture (cleanup/FX)
  • Ensemble Mode (blend models)
  • Audio Tools (pitch/time/EQ)

Center: Model & Stems

  • Choose Model dropdown
  • Vocals Only / Instrumental Only
  • All Stems (Demucs full split)

Right: Parameters

  • GPU Conversion toggle
  • Sample Mode (preview clip)
  • Segment Size / Overlap
  • Shifts (Demucs)
  • Window Size / Aggression
Bottom Bar: Wrench Icon (Settings & Download Center) · Progress Log Action: Start Processing
Parameter Recommended Setting Effect
GPU Conversion ON (NVIDIA CUDA) · OFF (CPU / Intel / Mac) Accelerates processing with CUDA; keep unchecked without an NVIDIA GPU to avoid crashes.
Sample Mode Checked for testing; unchecked for final render Processes a 5–30s snippet (length set in Wrench Settings) for fast model comparisons.
Segment Size 256 or Default (CPU/4GB VRAM) · 512 (8GB+) Controls chunk memory size in MDX-Net and Demucs; lower values prevent out-of-memory errors.
Overlap / Shifts Overlap 0.25 · Shifts 0–1 (CPU) / 2 (GPU) Overlap smooths chunk boundaries; Shifts averages multiple passes (2 doubles render time).
Window Size / Aggression Window 512 · Aggression 5 (VR Arch) Window sets analysis resolution (320 fast, 1024 smooth); raise Aggression (7–10) for less bleed, lower (2–4) if vocals thin out.

Lead vs. Harmony VR Arch — 5_HP-Karaoke-UVR / 6_HP-Karaoke-UVR Separates lead vocal line from background harmonies.
Noise Removal VR Arch UVR-DeNoise-Lite UVR-DeNoise Removes tape hiss, room noise, and static.
Ensemble Blending Ensemble Mode Any 2+ installed models MDX-Net + Demucs v4 Blends spectra via Max Spec, Min Spec, or Average.

Adding Models & Ensembles: Click the Wrench Icon → Download Center, choose VR Arch, MDX-Net, or Demucs, select a model from the dropdown, and click the download arrow. In Ensemble Mode, select multiple models and choose Min Spec / Max Spec (reduces bleed) or Average (balances tone), then save your combination as a preset.

3. DAW Production Notes

  • Dry Vocals (Two-Pass): Isolate the vocal in MDX-Net first, then feed the exported .wav back through VR Architecture using UVR-DeEcho-DeReverb or 5_HP-Karaoke-UVR before importing into your DAW.
  • Multi-Stem Sync: Export All Stems as WAV in Demucs and drag them together into your DAW timeline (hold Ctrl in Ableton Live to place each file on its own aligned track).
  • Audio Tools: Switch Process Method to Audio Tools for built-in Time Stretch (Rubberband), Change Pitch (semitone shift), and Matchering (automated EQ/loudness matching against a reference track).
